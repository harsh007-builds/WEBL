Setup & Dependency Commands
You don't need to manually download individual dependencies for this experiment; the create-react-app tool will handle all the heavy lifting. Run these commands in your terminal:


Verify Installation: Check that Node and npm are installed.  


node -v   


npm -v   


Create the App: Use this command to set up your new React project.  


npx create-react-app fetch-api-example   


Navigate to the Folder: * cd fetch-api-example   


Start the Development Server: This starts the local server on http://localhost:3000/.  


npm start
